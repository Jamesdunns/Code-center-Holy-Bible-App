HOLY BIBLE APP

Open this folder in Visual Studio Code and run index.html with Live Server.

Includes:
- Old and New Testament navigation
- All 66 book names and all chapter selectors
- Scripture reader interface
- Touch-friendly controls
- Previous/Next chapter navigation
- Search
- Verse selection
- Copy/share
- Dark mode
- Audio player
- Browser English text-to-speech fallback

DATA NOTE: This demo includes selected public-domain KJV sample passages and placeholders for the remaining chapters. To publish a complete Bible, replace bible-data.js with a complete public-domain or properly licensed Bible translation. Do not redistribute a copyrighted translation without permission.

AUDIO NOTE: Put properly licensed MP3 URLs in each chapter's audio property to use real recorded chapter audio. The app automatically falls back to browser text-to-speech when no MP3 is supplied.
